# M6: 开发路线图与学习资源

## 1. 总体开发节奏

智换项目分 **6 个阶段**，预计 **3-6 个月** 完成（独立开发）。

| 阶段 | 周期 | 目标 | 关键产出 |
|---|---|---|---|
| 阶段 1 | 第 1-2 周 | 环境搭建 + 基础架构 | 父工程 + Docker Compose + 14 个空壳服务 |
| 阶段 2 | 第 3-6 周 | 核心链路 MVP | 用户/商品/订单/支付/AI 跑通完整流程 |
| 阶段 3 | 第 7-10 周 | AI 智能体平台 | Graph + Multi-Agent + Agentic RAG 全部落地 |
| 阶段 4 | 第 11-14 周 | 高并发优化 | 缓存架构 + Feed 流 + 推荐系统 |
| 阶段 5 | 第 15-18 周 | 营销 / IM / 审核 / 通知 | 辅助服务完整化 |
| 阶段 6 | 第 19-24 周 | 可观测性 + 部署 + 性能调优 | Prometheus + ELK + SkyWalking |
