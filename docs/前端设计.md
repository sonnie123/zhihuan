
# 智换 (Zhihuan) 前端实现方案 — 让闲置价值重生

## Summary

为已有的 14 个后端微服务 `F:\file\learn\projects\JAVA\zhihuan` 新建一个独立的前端工程 `F:\file\learn\projects\JAVA\zhihuan\zhihuan-portal`,采用 **Vue 3 + Vite + TypeScript + Pinia + Vue Router 4** 技术栈,基于 **Element Plus**(PC 端 B 端/管理后台) + **Vant 4**(移动端 H5,如后续要做)双 UI 库,使用 **MSW (Mock Service Worker)** 模拟后端 14 个服务全部 Dubbo API,保留适配层供后续无缝切换真实 Gateway。

**品牌调性**: AI 科技感 — 渐变紫/青主色 + 玻璃拟态 + 现代转场动画,区别于闲鱼/转转的米黄色调,以"智换让闲置价值重生"为情感锚点。

**交付策略**: 分两阶段,先交付 5 个"门面"页面验证品质,再批量交付剩余 30+ 页面。

## 2. 设计系统(智焕 Design System)

**主色板 — AI 科技感渐变**:
- Primary: `#7C3AED`(紫) → `#06B6D4`(青),主渐变 `linear-gradient(135deg, #7C3AED 0%, #06B6D4 100%)`
- Accent: `#F59E0B`(琥珀,用于价格突出)
- Success: `#10B981`, Warning: `#F59E0B`, Danger: `#EF4444`, Info: `#3B82F6`
- 中性: 11 级灰阶 `#FFFFFF → #0F172A`

**字体**:
- 中文: `"PingFang SC", "Microsoft YaHei", sans-serif`
- 数字(价格): `"DIN Alternate", "Helvetica Neue", monospace`
- 全局基准: 16px,基准行高 1.5

**圆角**: 4/8/12/16/24px 阶梯

**阴影**: 4 级(卡片/悬浮/模态/抽屉),带品牌色微染

**动效**:
- 缓动: `cubic-bezier(0.4, 0, 0.2, 1)`(标准)、`cubic-bezier(0.34, 1.56, 0.64, 1)`(弹性)
- 时长: 150ms(微动)/ 250ms(常规)/ 400ms(强调)/ 600ms(页面切换)

**关键视觉模式**:
- **玻璃拟态**: `backdrop-filter: blur(20px) saturate(180%)` + 半透白底
- **渐变边框**: `border-image` + 渐变
- **微动效**: hover 上浮 2px + 阴影加深,150ms 过渡

### Page 3: AI 一键发布页 `/publish`

**目标**: **这是智焕的"核心卖点"**,AI 上架步骤动画必须做到"像调真实 MiniMax-M3 模型一样"。

**布局**:
- 步骤指示器(顶部 4 步): 上传图片 → AI 智能识别 → 编辑发布 → 提交审核
- 步骤 1 - 上传: 大号拖拽区 + 摄像头/相册按钮 + 一次最多 9 张 + 缩略图编辑
- 步骤 2 - AI 识别(**高保真动画,这是关键!**)：
  - 图片居中,周围环绕 5 个圆形 AI 节点(图识别/类目预测/估价/文案/审核)
  - 节点依次"激活" → 发光 → 扫描线扫过图片 → 该节点完成
  - 完成后图片下方依次"生成"内容(打字机效果):
    - 识别结果(品牌/型号/成色)滑入
    - 类目选择(三选一卡片)
    - 价格建议(¥1,200-1,400,中间值"AI 推荐"徽章)
    - 标题文案(带编辑入口)
    - 风险提示(绿色"通过"或黄色"需注意")
  - 顶部进度条 0→100% 平滑过渡,每步用不同的渐变色
  - 整个过程约 8-12 秒(可"跳过动画"按钮)
- 步骤 3 - 编辑: 左侧图片,右侧表单(标题/描述/类目/价格/原价/成色/地区/标签),所有 AI 生成内容可编辑
- 步骤 4 - 提交: 提交中 loading → 成功跳转商品详情(成功提示带"AI 已为你节省 8 分钟"话术)

**交互细节**:
- 节点激活时,节点中心图标有"呼吸"缩放动画
- 扫描线是渐变光带,从左到右扫描图片
- AI 生成文字是逐字打字机效果,带光标闪烁
- 表单字段聚焦时,顶部步骤指示器联动高亮当前字段
- 失败状态: 节点红色 + Toast 提示 + 降级方案(用规则引擎兜底)

```typescript
export const USE_MOCK = import.meta.env.VITE_USE_MOCK === 'true'

export async function request<T>(config: AxiosRequestConfig): Promise<T> {
  if (USE_MOCK) {
    // MSW 会在 axios 之前拦截
  }
  return http.request<T, T>(config)
}
```

`.env.development`: `VITE_USE_MOCK=true`、`VITE_API_BASE=/api`
`.env.production`: `VITE_USE_MOCK=false`、`VITE_API_BASE=http://localhost:9000`(Gateway)

切换真实后端时,只需:
1. 把 `.env.production` 的 `VITE_USE_MOCK` 改为 `false`
