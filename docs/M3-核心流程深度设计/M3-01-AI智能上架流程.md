# M3-01: AI 智能上架流程详细设计（Graph 工作流）

## 1. 流程概述

用户上传商品图片后，系统自动完成：识图 → 类目预测 → 价格建议 → 文案生成 → 风险审核，全程 30 秒以内完成。

这是项目 **最重要的核心流程**，展示了 Graph 工作流 + MiniMax-M3 多模态 + Agentic RAG 的综合应用。

## 2. 完整流程图

```
用户拍照上传
   ↓
[节点1: 图像识别] MiniMax-M3-Vision
   ↓
[节点2: 类目预测] MiniMax-M3 + 类目库
   ↓
[节点3: 价格建议] Agentic RAG（向量检索同类成交价）
   ↓
[节点4: 文案生成] Agentic RAG（检索爆款描述）
   ↓
[节点5: 风险审核] Aho-Corasick + MiniMax-M3-Safety
   ↓
[节点6: 收尾] 构造商品对象 + Kafka 事件
   ↓
返回商品 ID + AI 生成的内容（用户可编辑）
```

## 3. Graph 状态图定义

```java
@Configuration
public class ProductPublishGraphConfig {

    @Bean
    public StateGraph productPublishGraph(
            ImageRecognitionNode imageNode,
            CategoryPredictNode categoryNode,
            PriceEstimateNode priceNode,
            DescriptionGenNode descNode,
            RiskAuditNode auditNode,
            FinalizeNode finalizeNode) {

        StateGraph graph = new StateGraph("ProductPublish");

        graph.addNode("imageRecognition", imageNode);
        graph.addNode("categoryPredict", categoryNode);
        graph.addNode("priceEstimate", priceNode);
        graph.addNode("descriptionGen", descNode);
        graph.addNode("riskAudit", auditNode);
        graph.addNode("finalize", finalizeNode);

        graph.addEdge(StateGraph.START, "imageRecognition");
        graph.addEdge("imageRecognition", "categoryPredict");
        graph.addEdge("categoryPredict", "priceEstimate");
        graph.addEdge("priceEstimate", "descriptionGen");
        graph.addEdge("descriptionGen", "riskAudit");
        graph.addEdge("riskAudit", "finalize");
        graph.addEdge("finalize", StateGraph.END);

        return graph;
    }
}
```

### 4.1 图像识别节点

```java
@Component
public class ImageRecognitionNode implements NodeAction {

    @Resource
    private ChatClient chatClient;  // MiniMax-M3-Vision

    @Override
    public Map<String, Object> apply(OverAllState state) {
        log.info("[Graph] 图像识别节点开始");

        // 1. 从状态中获取输入
        @SuppressWarnings("unchecked")
        List<String> images = (List<String>) state.value("images").get();

        // 3. 构造多模态消息
        List<Media> mediaList = images.stream()
            .map(url -> new Media(MimeTypeUtils.IMAGE_PNG,
                new URL(url)))  // 下载图片
            .collect(Collectors.toList());

        UserMessage userMessage = UserMessage.builder()
            .text("请识别这张图片中的商品，输出 JSON 格式：\n" +
                "{\n" +
                "  \"brand\": \"品牌\",\n" +
                "  \"model\": \"型号\",\n" +
                "  \"category\": \"商品类别\",\n" +
                "  \"condition\": \"成色评分(0-10)\",\n" +
                "  \"color\": \"颜色\",\n" +
                "  \"material\": \"材质\",\n" +
                "  \"features\": [\"卖点1\", \"卖点2\"],\n" +
                "  \"defects\": [\"瑕疵1\"]\n" +
                "}")
            .media(mediaList)
            .build();

        // 4. 调用 MiniMax-M3
        String result = chatClient.prompt()
            .system("你是一个专业的商品鉴定师，擅长识别二手商品的品牌型号和成色")
            .user(userMessage)
            .options(ChatOptions.builder()
                .model("MiniMax-M3")
                .temperature(0.3)  // 降低随机性
                .responseFormat(ResponseFormat.JSON)  // 强制 JSON 输出
                .build())
            .call()
            .content();

        // 5. 解析结果并更新状态
        Map<String, Object> recognition = JsonUtil.parse(result);

        Map<String, Object> updates = new HashMap<>();
        updates.put("imageAnalysis", recognition);
        updates.put("brand", recognition.get("brand"));
        updates.put("model", recognition.get("model"));
        updates.put("condition", recognition.get("condition"));

        log.info("[Graph] 图像识别完成: brand={}, model={}",
            recognition.get("brand"), recognition.get("model"));

        return updates;
    }
}
```

### 4.3 价格建议节点（Agentic RAG）

```java
@Component
public class PriceEstimateNode implements NodeAction {

    @Resource
    private ChatClient chatClient;

    @DubboReference
    private SearchDubboService searchDubboService;

    @Override
    public Map<String, Object> apply(OverAllState state) {
        log.info("[Graph] 价格建议节点开始（RAG）");

        String brand = (String) state.value("brand").get();
        String model = (String) state.value("model").get();
        Double condition = (Double) state.value("condition").get();
        String categoryName = (String) state.value("categoryName").get();

        // ====== Agentic RAG：多路召回 ======

        // 路1: 向量检索（Milvus / ES dense_vector）
        String query = String.format("%s %s 成色%d %s",
            brand, model, condition.intValue(), categoryName);
        List<SimilarProductVO> vectorResults = searchDubboService
            .findSimilarProducts(query, topK = 20);

        // 路2: ES 全文检索（同关键词历史成交）
        List<SimilarProductVO> esResults = searchDubboService
            .searchSoldProducts(brand + " " + model, topK = 10);

        // 路3: MySQL SQL 结构化检索（同类目同品牌）
        List<SimilarProductVO> sqlResults = searchDubboService
            .searchSoldByCategory(brand, categoryName, topK = 10);

        // ====== Rerank 重排序 ======
        List<SimilarProductVO> reranked = rerank(query,
            mergeAndDedupe(vectorResults, esResults, sqlResults));

        // ====== MiniMax-M3 综合判断 ======
        String prompt = "你是一个专业的二手商品估价师。基于以下信息给出建议售价：\n\n" +
            "商品信息：\n" +
            "  品牌：" + brand + "\n" +
            "  型号：" + model + "\n" +
            "  成色：" + condition + "/10\n" +
            "  类目：" + categoryName + "\n\n" +
            "同类商品近期成交价参考（按相似度排序）：\n" +
            formatSimilarProducts(reranked) + "\n\n" +
            "请输出 JSON 格式：\n" +
            "{\n" +
            "  \"lowPrice\": 最低价,\n" +
            "  \"suggestedPrice\": 建议售价,\n" +
            "  \"highPrice\": 最高价,\n" +
            "  \"reason\": \"估价理由\",\n" +
            "  \"confidence\": 0.85\n" +
            "}";

        String result = chatClient.prompt()
            .system("你是专业的二手商品估价师，擅长根据同类商品成交价给出准确建议")
            .user(prompt)
            .options(ChatOptions.builder()
                .model("MiniMax-M3")
                .temperature(0.3)
                .responseFormat(ResponseFormat.JSON)
                .build())
            .call()
            .content();

        Map<String, Object> priceEstimate = JsonUtil.parse(result);

        Map<String, Object> updates = new HashMap<>();
        updates.put("priceEstimate", priceEstimate);
        updates.put("suggestedPrice", priceEstimate.get("suggestedPrice"));

        log.info("[Graph] 价格建议完成: suggestedPrice={}, confidence={}",
            priceEstimate.get("suggestedPrice"), priceEstimate.get("confidence"));

        return updates;
    }

    private List<SimilarProductVO> rerank(String query,
                                           List<SimilarProductVO> docs) {
        // 简化版 rerank：按相似度 + 时间衰减 + 销量加权
        return docs.stream()
            .sorted((a, b) -> Double.compare(b.getScore(), a.getScore()))
            .limit(10)
            .collect(Collectors.toList());
    }
}
```

```java
@Component
public class DescriptionGenNode implements NodeAction {

    @Resource
    private ChatClient chatClient;

    @DubboReference
    private SearchDubboService searchDubboService;

    @Override
    public Map<String, Object> apply(OverAllState state) {
        log.info("[Graph] 文案生成节点开始（RAG）");

        String brand = (String) state.value("brand").get();
        String model = (String) state.value("model").get();
        String categoryName = (String) state.value("categoryName").get();
        BigDecimal price = new BigDecimal(
            state.value("suggestedPrice").get().toString());

        // ====== Agentic RAG：检索爆款描述 ======
        // 路1: 向量检索（描述风格相似）
        List<String> topDescs = searchDubboService
            .findHotDescriptions(categoryName, topK = 5);

        // 路2: 平台热词 + 违禁词
        List<String> hotWords = searchDubboService.getHotWords(topK = 20);
        List<String> forbiddenWords = searchDubboService.getForbiddenWords();

        // ====== MiniMax-M3 生成 ======
        String prompt = "为以下二手商品撰写一段吸引人的商品描述：\n\n" +
            "商品信息：\n" +
            "  品牌：" + brand + "\n" +
            "  型号：" + model + "\n" +
            "  类目：" + categoryName + "\n" +
            "  价格：" + price + " 元\n\n" +
            "爆款描述风格参考：\n" +
            String.join("\n", topDescs) + "\n\n" +
            "必须包含的热词：" + String.join("、", hotWords) + "\n\n" +
            "禁止使用的词汇：" + String.join("、", forbiddenWords) + "\n\n" +
            "要求：\n" +
            "1. 150字以内，突出卖点\n" +
            "2. 真诚不夸张，避免违禁词\n" +
            "3. 引导买家咨询和下单";

        String description = chatClient.prompt()
            .system("你是爆款商品文案写手")
            .user(prompt)
            .options(ChatOptions.builder()
                .model("MiniMax-M3")
                .temperature(0.7)  // 提高创造性
                .build())
            .call()
            .content();

        // 同时生成标题
        String titlePrompt = "为这个商品生成一个吸引人的标题：\n" +
            brand + " " + model + "，" + categoryName + "，" + price + "元\n" +
            "要求：\n" +
            "1. 15字以内\n" +
            "2. 突出卖点\n" +
            "3. 包含关键词";

        String title = chatClient.prompt()
            .user(titlePrompt)
            .call()
            .content()
            .trim();

        Map<String, Object> updates = new HashMap<>();
        updates.put("description", description);
        updates.put("title", title);

        log.info("[Graph] 文案生成完成: title={}", title);

        return updates;
    }
}
```

### 4.5 风险审核节点（双引擎）

```java
@Component
public class RiskAuditNode implements NodeAction {

    @Resource
    private AhoCorasickMatcher matcher;

    @Resource
    private ChatClient safetyClient;

    @Override
    public Map<String, Object> apply(OverAllState state) {
        log.info("[Graph] 风险审核节点开始");

        String title = (String) state.value("title").get();
        String description = (String) state.value("description").get();
        String fullText = title + " " + description;

        // ====== 第一道：规则引擎（Aho-Corasick）======
        List<String> hitWords = matcher.match(fullText);
        if (!hitWords.isEmpty()) {
            Map<String, Object> updates = new HashMap<>();
            updates.put("hitWords", hitWords);
            updates.put("auditPass", false);
            updates.put("auditReason", "命中违规词: " + hitWords);
            log.warn("[Graph] 规则引擎命中违规词: {}", hitWords);
            return updates;
        }

        // ====== 第二道：AI 安全模型 ======
        String aiResult = safetyClient.prompt()
            .system("你是内容安全审核专家")
            .user("判断这段商品描述是否合规（色情/暴力/政治敏感/虚假宣传/违禁品/侵权）：\n\n"
                + fullText + "\n\n" +
                "返回 JSON：{safe: true/false, reason: \"原因\", confidence: 0.95}")
            .options(ChatOptions.builder()
                .model("MiniMax-M3")
                .temperature(0.1)
                .responseFormat(ResponseFormat.JSON)
                .build())
            .call()
            .content();

        Map<String, Object> aiAudit = JsonUtil.parse(aiResult);
        boolean safe = (Boolean) aiAudit.get("safe");

        Map<String, Object> updates = new HashMap<>();
        updates.put("hitWords", Collections.emptyList());
        updates.put("auditPass", safe);
        updates.put("auditReason", aiAudit.get("reason"));
        updates.put("auditConfidence", aiAudit.get("confidence"));

        log.info("[Graph] AI 审核完成: safe={}, confidence={}",
            safe, aiAudit.get("confidence"));

        return updates;
    }
}
```

### 4.6 收尾节点

```java
@Component
public class FinalizeNode implements NodeAction {

    @Override
    public Map<String, Object> apply(OverAllState state) {
        log.info("[Graph] 收尾节点开始");

        // 1. 整合所有结果
        AiPublishResult result = new AiPublishResult();
        result.setTitle((String) state.value("title").get());
        result.setDescription((String) state.value("description").get());
        result.setCategoryId(((Number) state.value("categoryId").get()).longValue());
        result.setCategoryName((String) state.value("categoryName").get());

        Map<String, Object> priceEstimate =
            (Map<String, Object>) state.value("priceEstimate").get();
        result.setSuggestedPrice(new BigDecimal(
            priceEstimate.get("suggestedPrice").toString()));
        result.setPriceLow(new BigDecimal(
            priceEstimate.get("lowPrice").toString()));
        result.setPriceHigh(new BigDecimal(
            priceEstimate.get("highPrice").toString()));
        result.setPriceReason((String) priceEstimate.get("reason"));

        result.setAiAuditStatus((Boolean) state.value("auditPass").get() ? 1 : 2);
        result.setAuditReason((String) state.value("auditReason").get());

        // 2. 返回最终结果
        Map<String, Object> updates = new HashMap<>();
        updates.put("aiPublishResult", result);

        log.info("[Graph] 全部节点执行完成: pass={}", result.getAiAuditStatus() == 1);

        return updates;
    }
}
```

## 5. 流程调用入口

```java
@Service
public class ProductPublishAIService {

    @Resource
    private StateGraph productPublishGraph;

    @Autowired
    private CompiledGraph compiledGraph;

    @Override
    public AiPublishResult generateProductInfo(List<String> images,
                                                 Long userId) {
        long start = System.currentTimeMillis();

        // 1. 准备初始状态
        Map<String, Object> initState = new HashMap<>();
        initState.put("images", images);
        initState.put("userId", userId);

        // 2. 执行 Graph
        OverAllState result = compiledGraph.invoke(initState);

        // 3. 获取最终结果
        AiPublishResult aiResult = (AiPublishResult)
            result.value("aiPublishResult").get();

        log.info("[Graph] 整个流程耗时: {} ms",
            System.currentTimeMillis() - start);

        return aiResult;
    }
}
```

## 7. 异常处理与降级

```java
// Graph 异常处理
@Configuration
public class GraphErrorHandler {

    @Bean
    public GraphRunner graphRunner(StateGraph graph) {
        return GraphRunner.builder()
            .graph(graph)
            .errorHandler((nodeName, exception, state) -> {
                log.error("Graph node {} failed", nodeName, exception);

                // 降级策略：使用规则引擎兜底
                if ("priceEstimate".equals(nodeName)) {
                    // 估价失败 → 返回默认价格
                    state.update("suggestedPrice", new BigDecimal("100"));
                    state.update("priceEstimate", Map.of(
                        "suggestedPrice", 100,
                        "reason", "系统估价暂时不可用，建议手动定价"
                    ));
                } else if ("descriptionGen".equals(nodeName)) {
                    // 文案生成失败 → 返回默认文案
                    state.update("description", "商品详情请咨询卖家");
                }

                return state;
            })
            .build();
    }
}
```
